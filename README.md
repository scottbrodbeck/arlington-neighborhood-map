# Arlington Neighborhood Map (ARLnow canon)

## Web app

`docs/` is a static neighborhood-lookup web app (GitHub Pages serves it from
this folder): a MapLibre GL map with the ARLnow neighborhoods overlaid, plus
search for an address (`3100 Columbia Pike`) or block (`2000 block of
N Quincy St`). Results are border-aware — an address within ~80 m of another
neighborhood reports "on the border of X and Y." Clicking anywhere on the map
gives the same readout.

- Basemap: OpenFreeMap `positron` (keyless, free). Geocoding: Arlington
  County GIS (`arlgis.arlingtonva.us`, authoritative) with the U.S. Census
  geocoder as a JSONP fallback. No API keys, no backend.
- Local dev: `.venv/bin/python scripts/dev_server.py` → http://127.0.0.1:8741
- Data files (`docs/neighborhoods.json`, `docs/labels.json`,
  `docs/county.json`) are generated by `scripts/build_neighborhoods.py` —
  regenerate after any boundary change.

`arlington_neighborhoods.geojson` is ARLnow's canonical neighborhood boundary
file: Arlington County's civic association polygons with the newsroom's
hand-annotated wall-map changes applied. **67 features**, same property schema
as the county file (`CIVIC` / `LABEL` hold the neighborhood name).

## MCP server (for Claude)

`mcp-server/` is a Cloudflare Worker that exposes the same lookup to Claude as a
remote **MCP connector**, so the newsroom's writing Project can ask which
neighborhood an address is in and get the identical answer to the map (it reuses
`docs/classify.js` and the same polygon data — single source of truth).

- **Live endpoint:** `https://arlnow-neighborhoods-mcp.local-news-now-group.workers.dev/mcp`
- **Tools:** `lookup_neighborhood` (address or "NNNN block of ST"),
  `lookup_by_coordinates` (lat/lng), `list_neighborhoods` (canonical names).
  Each returns a ready-to-quote sentence plus structured JSON.
- **Arlington-only by design:** it uses only the Arlington County GIS geocoder
  (no national geocoder), gates every path through the county outline, and
  returns a bare "Address not in Arlington." — with no coordinates — for
  anything outside the county. It cannot be used as a general geocoder.
- **Auth:** authless; abuse-capped by a Cloudflare rate-limit binding.

Connect it in Claude: **Settings → Connectors → Add custom connector**, paste the
`/mcp` URL. On Team/Enterprise an Owner adds it org-wide; then enable it in the
Project. (Free plans allow one custom connector.)

Develop & deploy:

```
cd mcp-server
npm install
npx wrangler dev                         # local: http://127.0.0.1:8787/mcp
node test-client.mjs <baseUrl>/mcp       # runs the verification checklist
npx wrangler deploy                      # MUST run from mcp-server/
```

The Worker **bundles** `docs/neighborhoods.json` / `docs/county.json` at build
time. After any boundary change: rerun `scripts/build_neighborhoods.py` (the site
auto-deploys via Pages) **and** `npx wrangler deploy` from `mcp-server/` to pick
up the new data.

Inputs (all checked in under `data/`):

- `data/Civic_Association_Polygons.geojson` — Arlington County civic

- `data/osm/` — OpenStreetMap extracts (street centerlines, the county
  boundary, and the DCA airport polygon) used for split lines and gap fills.

## Judgment calls worth a second look

The marker lines are roughly a block wide at map scale, so the exact split
streets are interpretations:

1. **Clarendon/Courthouse divider = N. Barton St.** The drawn line passes
   between N. Barton and N. Adams; Barton was chosen because it spans the full
   polygon from Key Blvd to 10th St N (Adams stops at Clarendon Blvd).
2. **Rosslyn's southern edge = 14th St N.** The drawn line runs between
   14th Rd N and Fairfax Dr.
3. **Pentagon City's southern notch** keeps the Aurora Hills
   library/community-center block in Aurora Highlands, per the drawing.
4. **Potomac Yard** includes the US-1 right-of-way sliver down to Four Mile
   Run. The OSM airport polygon over-extends north of the real airfield (it
   covers the Capital View hotel block), so the airport is only subtracted
   south of the 33rd St S line.
5. Still intentionally unassigned: the airport, the Pentagon, Arlington
   National Cemetery, the GW Parkway shoreline, Army Navy Country Club,
   and island parks like Lubber Run — no street addresses there.

## Quick lookup example

```python
import json
from shapely.geometry import shape, Point

feats = json.load(open('arlington_neighborhoods.geojson'))['features']
pt = Point(-77.0599, 38.8627)            # lon, lat from any geocoder
print(next(f['properties']['CIVIC'] for f in feats
           if shape(f['geometry']).contains(pt)))   # -> Pentagon City
```
